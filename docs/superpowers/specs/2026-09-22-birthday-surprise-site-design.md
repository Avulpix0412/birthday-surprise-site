# 生日惊喜网站 — 设计文档

日期：2026-09-22
目标日期：2026-09-25（女朋友生日）

## 目的与成功标准

给女朋友做一个手机（iPhone，中国大陆网络环境）上打开即可体验的生日惊喜网站，通过微信分享链接送达。要求：
- 体验时长 5-10 分钟，不是"一两分钟逛完"的单薄页面
- 有动画、有互动，节奏富于变化
- 不需要账号/密码/后端，纯前端静态站，微信内置浏览器打开流畅
- 最终揭晓情书文字 + 礼物/旅行计划

## 整体结构

单页应用（滚动式，非多 HTML 页面），共 4 个区块：

1. **封面**：手写体标题 + 点击/滑动开始的引导动效
2. **回忆时间线**：6-8 个回忆节点，每个节点包含照片轮播 + 故事文字 + 一个"当时的小细节"彩蛋。节点之间用 Intersection Observer 触发滚动进入动画
3. **互动环节**（穿插在回忆节点之间，制造节奏变化，非连续堆叠）：
   - 拼图小游戏：拼出一张照片才显示完整回忆内容
   - 转盘/翻牌抽取：随机或固定顺序揭示"我们的第一次___"卡片
   - 点击搜索彩蛋：页面中隐藏 2-3 个可点击的贴纸/爱心图标，点中弹出小惊喜文字
4. **揭晓页**：情书式文字动画（逐句浮现，信件展开效果）→ 接礼物/旅行计划揭晓动画 → 彩带效果（canvas-confetti）→ 背景音乐持续播放至此

## 视觉风格

浪漫粘土/手账风：暖色调、手绘感插画/贴纸装饰、手写体字体、纸张/胶带/贴纸的视觉元素贯穿全站。

## 技术方案

- 纯前端：HTML + CSS + 原生 JavaScript
- 动画：CSS animation/transition + Intersection Observer（滚动触发），无需引入前端框架
- 拼图、转盘：轻量原生 JS 实现（不引入重型游戏库）
- 彩带效果：canvas-confetti（唯一外部依赖，CDN 引入）
- 音频：`<audio>` 元素，用户完成首次互动（点击开始/解锁）后才播放，规避浏览器/微信自动播放限制
- 目标环境：微信内置浏览器 + iOS Safari，需实测两者兼容性

## 内容与素材

先用占位内容（示例照片、示例文字）搭建完整框架和全部动画/互动效果。框架效果确认后，替换为用户提供的：
- 真实照片（每个回忆节点若干张）
- 故事文字（每个回忆节点的叙述 + 小细节彩蛋）
- 情书文字
- 礼物/旅行计划的具体内容
- 指定背景音乐文件（mp3）

素材替换预留清晰的占位标记（如 `data-placeholder` 注释或独立数据文件），方便后续直接替换而不用改动结构代码。

## 部署

GitHub Pages。新建独立仓库（与用户现有个人主页仓库分开），部署后生成链接，通过微信分享给女朋友。

## 测试

- 用 `/browse` 或 `/qa` 技能在浏览器中验证：滚动动画触发、拼图/转盘互动可完成、音频在解锁后播放、彩带效果正常
- 检查移动端视口下的布局（无横向滚动、点击区域够大）
- 若条件允许，实际用 iPhone 微信内置浏览器打开验证一次

## 范围之外（不做）

- 用户账号/登录
- 后端服务器/数据库
- 密码/答题式解锁（用户明确选择了非密码式简单互动）
- 复杂 3D 效果或重型游戏引擎
